# Privacy Policy for ConstTool - Developer Toolkit

**Last Updated:** October 8, 2026

ConstTool - Developer Toolkit does not collect, store, or transmit any user data.

All operations, including UUID generation, JSON formatting, regular expression testing, and timestamp conversion, are performed locally within your browser. No data is sent to any external server. The extension is fully offline-capable and requires no network connection to function.

We do not track your usage, we do not collect personal information, and we do not share any data with third parties.
